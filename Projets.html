Projet 1 : Conception du jeu Snake en language C

Projet 2 : Création d'un algorithme K-Nearest Neighbors (KNN)

Détails du projet & Objectifs d'apprentissage

Implémentation from scratch de l'algorithme de classification non-paramétrique K-Nearest Neighbors (KNN). Le but était de maîtriser les fondamentaux du Machine Learning en Python en se concentrant sur les notions de distance et de classification d'instances.

Objectifs :
  • Analyser un problème et le décomposer en éléments algorithmiques simples.
  • Mise en œuvre d'une structure de données adaptée.
  • Comparer les performances de l'algorithme avec des problèmes classiques.
Technologies/Compétences :

Projet 4 : Conception et Optimisation de Base de Données Relationnelle

Détails du projet & Modélisation

Projet complet de modélisation et d'implémentation d'une base de données (BDD). L'objectif était de garantir l'intégrité, la performance et l'évolutivité des données en passant d'un modèle existant à un modèle relationnel optimisé.

Étapes clés :
  • Étape 1 : Critique du modèle existant et proposition d'un nouveau modèle logique (via script SQL).
  • Étape 2 : Réponse aux requêtes complexes (via script SQL).
  • Étape 3 : Extension de la BDD (diagramme de classe, implémentation SQL et jeu de données test).
Technologies/Compétences :
  • SQL (DDL/DML)
  • Modélisation (UML/Merise)
  • Optimisation de Schéma
  • Requêtes complexes
